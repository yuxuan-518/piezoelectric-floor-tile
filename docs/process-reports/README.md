# Process summaries and laboratory reports

These Chinese documents record the team's development process. They include exploratory explanations, simulation notes, and proposed tests as well as experimental observations. A proposed test in a report is not evidence that it was completed.

The [current experiment definitions](../experiments.md) incorporate the team's November 4 clarifications: A is the one-disc adaptation of V1, B is V3, and the A/B storage capacitor is 4.7 μF. Older eight-disc V1 and 2.2 μF configurations remain historical records.
