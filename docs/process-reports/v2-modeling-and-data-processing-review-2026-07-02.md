# 0. 一句话总览
本项目的核心问题是：在人踩地板导致上板下压和回弹时，零初始间隙的弹簧-撞击物模块能否发生“接触、脱离、自由回弹、再次撞击”的过程。我们最终用真实踩踏曲线做事件驱动仿真，发现方案有希望，当前最值得进一步实验验证的参数范围是 100–150 g 撞击物和 0.5–1.0 N/mm 弹簧。

| --- | --- | --- | --- |

| 备选 1 | 150 g | 0.5 N/mm | fast_1 曲线下 1 次撞击，v_rel 约 1.11 m/s |

# 1. 真实结构与仿真目的
真实装置由两个功能不同的系统组成：地板支撑/限位系统和撞击发电模块。地板支撑系统负责承受人体踩踏，使上层木板产生局部位移；撞击发电模块由弹簧和撞击物组成，目标是在地板运动驱动下产生脱离和再撞击。

| 系统 | 真实作用 | 仿真中的角色 |
| --- | --- | --- |
| 地板支撑/限位系统 | 承受踩踏、限制最大下压、产生回弹曲线 | 提供地板输入 y_p(t) |
| 撞击发电模块 | 弹簧和撞击物组成，不支撑地板 | 被 y_p(t) 驱动，扫描 m、k、e |

- 当前仿真不直接预测发电量，只做机械可行性筛选。
- 第一阶段不推荐具体商品弹簧，只缩小质量和刚度范围。
- 压电片破裂风险暂时只用撞击速度和能量做相对比较，不能等同于真实破裂预测。


# 2. 坐标、变量和核心物理模型
整个仿真统一规定：向下为正方向。这个约定非常重要，因为脱离判断、速度方向和碰撞公式都依赖它。

| 变量 | 含义 | 单位/说明 |
| --- | --- | --- |
| y_p(t) | 地板压缩位移 | m，向下为正 |
| v_p(t) | 地板速度 | m/s，回弹向上时为负 |
| a_p(t) | 地板加速度 | m/s² |
| y_m(t) | 撞击物相对静平衡位置位移 | m，向下为正 |
| v_m(t) | 撞击物速度 | m/s |
| m | 撞击物质量 | kg |
| k | 弹簧刚度 | N/m；1 N/mm = 1000 N/m |
| e | 碰撞恢复系数 | 0 到 1，越大越弹 |
| N(t) | 地板对撞击物接触力 | N，N<0 代表地板必须拉它，物理上不可能 |


## 2.1 接触阶段
接触阶段假设撞击物被地板顶着一起运动，因此 y_m(t)=y_p(t)。接触力为：
```
N(t) = m * a_p(t) + k * y_p(t)
第一版 c = 0，因此没有连续阻尼项。
```
如果 N(t) ≥ 0，地板仍然能推着撞击物。若 N(t) < 0，说明若要继续接触，地板必须对撞击物产生拉力，但真实结构中木板只能推不能拉，所以判定脱离。

## 2.2 脱离后自由运动
脱离后撞击物不再跟随地板，只受弹簧回复力作用，满足无阻尼弹簧振子方程：
```
m * y_m'' + k * y_m = 0
ω = sqrt(k / m)
```
用解析解而不是普通积分，是为了避免数值误差累积，也让事件检测更清楚。
```
y_m(t) = y0*cos(ω(t-t0)) + (v0/ω)*sin(ω(t-t0))
v_m(t) = -y0*ω*sin(ω(t-t0)) + v0*cos(ω(t-t0))
```

## 2.3 再撞击
脱离后不断寻找 y_m(t)-y_p(t)=0 的下一个根，并要求相对速度方向正确。碰撞速度更新公式为：
```
v_m_after = v_p - e * (v_m_before - v_p)
```

# 6. 关键错误、为什么错、如何修

| 问题 | 为什么会错 | 修复方式 | 学到什么 |
| --- | --- | --- | --- |
| 把 N→0 边界当成脱离 | 地板回到零位时 N 可能接近 0，但没有真正进入 N<0 | 先确认 N<-0.005N，再回溯 N=0 | 事件检测不能只看等于零，要看是否穿过零并进入负区间 |
| 把 N=-0.005N 时刻当脱离时刻 | 阈值只是防伪迹，物理脱离点仍是 N=0 | 两步法：阈值确认，N=0 报告 | 报告给论文的事件时间必须对应物理定义 |
| measured_v1 末尾伪脱离 | np.clip 让 v_p、a_p 在 t>t_max 保持端点导数 | 显式设数据段外 v=0、a=0 | 边界条件比公式本身更容易制造假结论 |
| 末尾负 compression 导致 N<0 | 少量 -0.5~-2.5mm 可能是读数/零点误差，长期保留会让 N=k*y_last<0 | 新增 raw 与 clamp 预处理对比 | 原始数据要保留，但论文主分析要说明预处理逻辑 |
| recommended 字段误用 | 它来自早期参数化模型语境，不适合直接当真实曲线论文结论 | 新增 is_valid_detach_for_paper 与 candidate_grade | 工程筛选字段要随研究问题演进 |
| 过度相信插值时间精度 | CSV 是 100Hz，原始间隔 0.01s；插值给出的 1e-7s 不是真实测量精度 | 论文中按 ms 级报告，并注明数据为 100Hz 插值 | 数值精度不等于物理精度 |

用户提供的 Excel 文件包含快踩和慢踩数据。Codex 将其拆成 6 条 CSV 曲线，放在 data/ 中。每条 CSV 只有两列：time_s 和 compression_mm。时间统一从 0 s 开始，压缩量向下为正。

| CSV | 行数 | 时长 | 压缩量范围 |
| --- | --- | --- | --- |
| fast_1.csv | 33 | 0.32 s | 0.0 到 32.0 mm |
| fast_2.csv | 32 | 0.31 s | 0.0 到 31.0 mm |
| fast_3.csv | 33 | 0.32 s | -1.0 到 25.0 mm |
| slow_1.csv | 44 | 0.43 s | -2.5 到 33.0 mm |
| slow_2.csv | 38 | 0.37 s | -1.0 到 34.0 mm |
| slow_3.csv | 41 | 0.40 s | -0.5 到 35.0 mm |

末尾负值没有从原始 CSV 中删除，而是在仿真读取时用 preprocess 选项做对比：raw 保留，clamp 在回弹后接近零点处将负值裁到 0。

# 8. 平滑和预处理为什么重要
真实曲线只有约 32–44 个点，采样频率约 100Hz。位移数据看似平滑，但速度和加速度来自求导，噪声会被放大。

| 选项 | 含义 | 风险 |
| --- | --- | --- |
| smooth=none | 直接三次样条插值 | 保留原始形状，但端点和局部震荡可能放大加速度 |
| smooth=savgol | Savitzky-Golay 平滑 | 能抑制噪声，但短数据末端可能出现边界效应 |
| smooth=butter | 低通滤波 | 短序列下容易产生末尾相位/边界扭曲 |
| preprocess=raw | 完全保留原始负值 | 适合作敏感性附录，不宜单独作为主结论 |
| preprocess=clamp | 峰后回到零附近后，将负压缩裁为 0 | 适合作论文主分析，但要说明假设 |

# 10. 结果分级逻辑
最终不是只看是否脱离，而是看脱离是否可信、是否有撞击、撞击速度是否足够。

| 字段 | 判断逻辑 | 论文中怎么用 |
| --- | --- | --- |
| is_tail_detach_20ms | 脱离发生在数据末尾 20ms 内 | 标记为可疑，不做主结论 |
| is_early_detach_20ms | 脱离发生在数据开头 20ms 内 | 标记为可疑，不做主结论 |
| is_valid_detach_for_paper | 非 tail、非 early、impact_count>0 | 论文可用基础筛选 |
| strong | valid 且 v_rel ≥ 0.5 m/s | 主候选 |
| moderate | valid 且 0.1≤v_rel<0.5 m/s | 补充分析 |
| borderline | valid 且 0.05≤v_rel<0.1 m/s | 敏感性讨论 |

# 14. 论文中可以怎么写
建议论文中的表述要保守、工程化，不要把仿真结果写成绝对最优。

# 15. 论文中不能直接说什么
- 不能说已经找到最终最优弹簧型号。
- 不能说所有踩踏条件下都稳定有效。
- 不能把 recommended 字段当论文结论依据。
- 不能把 1e-7 s 的事件时间当真实实验精度。
- 不能把仿真撞击能量直接等同于发电量。
- 不能做压电片破裂的定量结论，除非后续有压电片强度参数和实验校准。

# 17. 学习路线：你应该怎么理解这套仿真
- 第一层：先懂变量和方向。向下为正，N<0 表示需要拉力，所以脱离。
- 第二层：懂事件。仿真不是每一帧硬算，而是找脱离和撞击这两个事件。
- 第三层：懂数据。位移曲线看起来简单，但速度和加速度来自求导，最容易被噪声污染。
- 第四层：懂版本。每个版本都是为了解决一个具体假象，不是随便改代码。
- 第五层：懂结论。论文不是写“最大值”，而是写“在假设和数据处理条件下的候选范围”。
