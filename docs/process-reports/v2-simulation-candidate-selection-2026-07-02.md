# 仿真结论阅读过程整理
整理日期：2026-07-02
这份文档的目的不是教你从零写仿真代码，而是让你能看懂：最终结论是怎么从真实数据、筛选规则、结果表和图表一步步推出来的。

# 1. 最终结论先放在前面
当前最建议写进论文主分析的候选组合是：100 g 撞击物 + 0.5 N/mm 弹簧，使用 fast_3 真实踩踏曲线、preprocess=clamp、smooth=none。

| 结论项 | 当前结果 | 怎么理解 |
| --- | --- | --- |
| 主推荐组合 | m=100 g, k=0.5 N/mm | 不是最终商品型号，而是后续实物实验优先验证点 |
| 依据曲线 | fast_3 | 在真实快踩曲线下表现最强 |
| 撞击表现 | 2 次撞击 | 说明不是只发生一次偶然接触 |
| 最大相对速度 | 约 1.17 m/s | strong 候选中最高，机械激励较明显 |
| 最大撞击能量 | 约 68.3 mJ | 能量适中，不是最猛烈但较均衡 |
| 论文表述 | 候选参数范围 | 不要写成绝对最优或最终设计 |


# 2. 结论不是直接看最大值，而是经过四层筛选
最终结论不是从一张图里随便挑最高值，而是经过以下顺序判断。

| 层级 | 筛选问题 | 保留条件 | 为什么这样做 |
| --- | --- | --- | --- |
| 第一层 | 有没有脱离？ | detach=True | 如果不脱离，就没有自由回弹和再撞击过程 |
| 第二层 | 脱离是否可信？ | 不是开头 20ms，也不是末尾 20ms | 排除样条边界、末尾读数等伪迹 |
| 第三层 | 有没有再撞击？ | impact_count > 0 | 只有脱离但没撞回来，对压电撞击发电意义有限 |
| 第四层 | 撞击强不强？ | v_rel >= 0.5 m/s 为 strong | 用相对速度作为机械激励强弱的主指标 |


# 3. 读结果表时只看这些字段
真正判断结论时，不需要盯着所有列。重点看下面这些列即可。

| 字段 | 意思 | 阅读方法 |
| --- | --- | --- |
| trial | 哪条真实踩踏曲线 | fast_1/2/3 是快踩，slow_1/2/3 是慢踩 |
| preprocess | 数据预处理方式 | 论文主分析看 clamp，不把末尾负压缩误差直接当结论 |
| smooth | 平滑方式 | 主结论使用 none；savgol/butter 主要做敏感性参考 |
| m_g, k_Nmm | 质量和弹簧刚度 | 这就是最后要讨论的参数组合 |
| detach_time_paper_s | 论文引用的脱离时间 | 换算成约多少 ms，不要引用过细小数 |
| impact_count | 撞击次数 | 至少要大于 0，但不能单独作为唯一依据 |
| max_rel_speed_ms | 最大相对撞击速度 | 最核心的强弱指标 |
| max_impact_energy_mJ | 最大撞击能量 | 辅助比较猛烈程度 |
| is_valid_detach_for_paper | 是否可用于论文 | False 的组合不要拿来做主结论 |
| candidate_grade | 候选级别 | strong 才进入主候选表 |


# 4. 总体数据分布怎么看
measured_v3_summary 使用 preprocess=clamp 的 216 组结果进行论文候选分级。分级结果如下。

| 级别 | 数量 | 含义 | 论文用途 |
| --- | --- | --- | --- |
| strong | 5 | 有效脱离 + 有撞击 + v_rel >= 0.5 m/s | 主结论候选 |
| moderate | 26 | 0.1 <= v_rel < 0.5 m/s | 补充分析 |
| borderline | 16 | 0.05 <= v_rel < 0.1 m/s | 敏感性讨论 |
| below_threshold | 12 | 有效但速度太小 | 不作为主结论 |
| suspicious | 104 | 开头/末尾附近脱离，可能是边界或数据效应 | 排除 |
| no_detach | 53 | 没有脱离 | 排除 |

这一步说明：论文结论不是来自所有 216 组，而是从 216 组中剔除可疑和无效结果，再从有效结果中选 strong。

# 8. 逻辑链条：从真实曲线到论文结论

| 步骤 | 输入/判断 | 输出 |
| --- | --- | --- |
| 1 | 读取真实踩踏曲线 time_s 与 compression_mm | 得到地板位移 y_p(t) |
| 2 | 对 y_p(t) 插值/求导 | 得到地板速度 v_p(t) 与加速度 a_p(t) |
| 3 | 计算 N(t)=m*a_p(t)+k*y_p(t) | 判断是否脱离 |
| 4 | 脱离后用弹簧振子解析解 | 计算撞击物自由运动 y_m(t) |
| 5 | 寻找 y_m(t)=y_p(t) 且相对速度方向正确 | 判断再撞击 |
| 6 | 排除 early/tail 可疑事件 | 得到论文有效事件 |
| 7 | 按 v_rel 分 strong/moderate/borderline | 得到最终候选组合 |


# 9. 为什么结论偏向 fast_1 / fast_3
fast_1 和 fast_3 是快踩曲线，它们的回弹段更容易给撞击物造成脱离条件。脱离不是只由最大位移决定，而是由位移和加速度共同决定。也就是说，地板回弹得越急，越可能让 N(t) 变成负值。
```
N(t) = m * a_p(t) + k * y_p(t)
当回弹加速度足够强时，m*a_p(t) 项可能把 N(t) 拉到负值，从而触发脱离。
```

# 10. 论文可以怎么写
可以使用下面这种保守表述。
```
基于实测地板位移曲线的事件驱动仿真结果表明，零初始间隙撞击模块在部分快踩输入下能够产生脱离与再撞击。在 preprocess=clamp、smooth=none 的主分析条件下，100 g 撞击物与 0.5 N/mm 弹簧刚度组合在 fast_3 曲线中产生 2 次撞击，最大相对撞击速度约为 1.17 m/s，最大撞击能量约为 68.3 mJ。该组合可作为后续实物实验的优先候选参数。
```

# 11. 论文里不要过度说的内容
- 不要说已经找到最终最优弹簧型号。
- 不要说所有踩踏速度和所有人群下都有效。
- 不要把仿真撞击能量直接等同于发电量。
- 不要把可疑脱离区域写成有效结论。
- 不要把 100Hz 数据插值得到的很多小数位当成真实实验精度。


# 12. 一句话答辩版
如果答辩时被问“你的结论怎么看出来的”，可以这样答：
```
我先用真实踩踏位移曲线作为地板输入，再通过 N(t)=m*a_p(t)+k*y_p(t) 判断撞击物是否脱离。脱离后用弹簧振子的解析解寻找是否再次撞击，并排除了开头和末尾 20ms 内的可疑事件。最后按最大相对撞击速度分级，只有有效脱离且 v_rel>=0.5 m/s 的组合被列为 strong。在这些 strong 候选里，100 g + 0.5 N/mm 在 fast_3 曲线下产生 2 次撞击，v_rel 约 1.17 m/s，所以作为当前优先候选。
```
